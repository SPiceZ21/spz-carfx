## Overview

`spz-carfx` is the dedicated resource for managing high-performance vehicle visual effects within the ecosystem. It provides custom particle libraries and logic for triggering immersive feedback such as backfire flames, nitrous oxide purges, and specialized tire smoke, specifically tuned for competitive racing environments.

---

## Features

- **Particle Libraries** — Custom `.ypt` files (core and mods) for high-fidelity vehicle effects.
- **Nitro Effects** — Enhanced visual feedback for nitrous oxide systems.
- **Exhaust Pops & Bangs** — Dynamic particle triggers for high-performance engine tuning.
- **Optimized Streaming** — Lightweight asset management designed for performance-heavy race environments.
- **Native Integration** — Seamlessly hooks into `spz-physics` for physics-driven visual feedback.
